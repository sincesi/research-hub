## Organization

- This hub indexes papers and links to their artifacts; it does not duplicate large datasets or model archives.
- Each new paper gets a dedicated repository with a descriptive, stable name.
- Each paper repository documents its model, data sources, dependencies, execution commands, expected results, and limitations.
- Verified milestones become tagged releases. A repository connected to Zenodo can archive those releases with version-specific DOIs.
- Preserve released versions. Publish corrections as new versions with a changelog.
- Keep the existing IEEE Access archive and DOI unchanged; link it here rather than moving its historical release.
- Add future papers only when their public metadata and artifact destination are ready.

Use [the paper entry template](templates/paper-entry.md) for the next paper and [the repository guide](REPOSITORY_GUIDE.md) to prepare its artifact.
