# ABZ 2026

**Paper:** Relational Verification of Identity Disclosure Using Alloy  
**Authors:** Seungil Yang, Peter Rivière, Toshiaki Aoki  
**Artifact:** https://github.com/sincesi/abz-2026-artifact

The artifact reconstructs the original ABZ-style schemas, transformation relations and attacker matching relations. The Table 2 executable adds non-zero bounded noise and original/external consistency explicitly. It is not represented as the unchanged historical publication executable.

| Case | Verified outcome |
|---|---|
| Generalization + Exact | SAT |
| Deletion + Exact | SAT |
| Noise + Approx | SAT |
| Noise + Exact | UNSAT |

The repository retains the earlier diagnostic model, which shows why each additional assumption is needed. See its README for bounds, overflow handling, and reproduction commands.
